# Third-party material

## Palette data

The 144- and 221-color tables are attributed in the original source to the
Pixelbead 2026 MARD color chart. The 24-color table retains the project's
original values and names; identical codes need not have identical RGB values
between the 24-color and larger palettes.

The maintainer confirmed permission to publicly redistribute the included
color values and names during release preparation on 2026-09-07. No upstream
source URL or permission document was supplied with that confirmation.
This records the maintainer's confirmation, not independent legal verification
or a claim that the upstream chart is MIT-licensed. The code license does not
grant rights to upstream chart artwork, trademarks, or reference photographs.

## Dependencies and images

Rust dependencies retain their own licenses; exact versions are in Cargo.lock.
Local reference photographs, screenshots, and the output directory are not
part of this release. No rights to those local assets are granted here.
